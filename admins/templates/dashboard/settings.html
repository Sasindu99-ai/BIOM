Quickstart with biom-kit
How to use your API key in Google Colab / Jupyter

1. Install the public package via pip:

pip install biom-kit

2. Authenticate and query in your notebook:

import biom

# Authenticate (connects to https://biom.arceion.com by default)
biom.login("YOUR_API_KEY")

# Discover available fields & datasets
print(biom.fields())
print(biom.datasets())

# Filter and retrieve data directly into pandas
df = biom.dataset(1).filter(age__gte=18).to_dataframe()
print(df.head())
Security Tip: You can also set the BIOM_API_KEY environment variable in your system or Colab Secrets instead of hardcoding keys in notebooks.
