Step 1 Authenticate & Discover Cohorts 
import biom

# Authenticate using your live API key
biom.login(api_key="{% if active_key %}{{ active_key.key_prefix }}...{% else %}biom_live_your_api_key_here{% endif %}")

# Discover all published clinical cohorts
datasets = biom.datasets()
print(datasets[["id", "name", "records", "variables"]])

# Inspect variables and measurement units for a specific dataset
variables = biom.variables(dataset=1)
print(variables.head())
Step 2 Fluent Querying & DataFrame Extraction 
# Query cohort with multi-variable constraints into a Pandas DataFrame
cohort_df = (
    biom.dataset(1)
    .filter(age__gte=18, age__lte=65)
    .filter(gender="Female")
    .filter("Serum Creatinine", gt=1.2)
    .to_dataframe()
)

print(f"Loaded {len(cohort_df)} harmonized patient records")
print(cohort_df.describe())
Step 3 Exploratory Analysis & Publication Figures 
from biom import tools

# 1. Missingness & data health report
health_report = tools.summarize_health(cohort_df)

# 2. Generate publication-quality biomarker distribution plot
tools.plot_distribution(
    cohort_df,
    column="eGFR",
    group_by="CKDu_Status",
    save_path="egfr_distribution.png"
)

# 3. Compute and plot correlation matrix across omics variables
tools.plot_correlation_matrix(cohort_df, save_path="biomarker_correlation.png")
REST Architecture

Core API Endpoints Reference

Direct HTTP access for custom pipelines, cURL scripts, and non-Python integrations.

GET /api/v1/study/ Public / Authenticated
List Studies & Cohorts

Retrieve paginated list of published cohorts with sample counts and metadata.

curl -H "Authorization: Bearer YOUR_API_KEY" \
     "https://biom.arceion.com/api/v1/study/?page=1&limit=10"
GET /api/v1/study/{id}/ Public / Authenticated
Study Details & Variable Schema

Retrieve detailed cohort variables, measurement protocols, and results.

curl -H "Authorization: Bearer YOUR_API_KEY" \
     "https://biom.arceion.com/api/v1/study/1/"
GET /api/v1/study/biomarkers/ Public
Biomarker Knowledge Atlas

Query molecular markers across conditions, tissues, and assay platforms.

curl "https://biom.arceion.com/api/v1/study/biomarkers/?search=KIM-1"
GET /api/v1/kit/discover/datasets biom-kit Protocol
